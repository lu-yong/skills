# 门禁技能绝不降级，对话技能可降级为 markdown 提问

本仓库的技能通过宿主的结构化提问工具（pi 的 `ask_user_question`）向用户提问。判定标准是**答案的后果**：答案只影响对话走向的技能是对话技能（如 `grilling`），工具缺失或调用出错时降级为 markdown 提问即可，零风险；答案会授权写操作或外部动作的技能是门禁技能（`commit-gerrit`、`update-issue-conclusion`、`refresh-bu1-sdk-rules`），必须停止并报告，绝不降级为自然语言确认——降级会打开"模型误读一句自然语言就触发写操作"的口子。新增需要向用户提问的技能时，先按这条标准归类，再决定契约与降级策略。
