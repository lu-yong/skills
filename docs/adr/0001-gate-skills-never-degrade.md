# 门禁技能绝不降级，对话技能可降级为 markdown 提问

以答案的后果确定提问方式。答案只影响对话走向时，优先用结构化提问工具。工具缺失或失败时，对话技能可改用 Markdown 提问。

答案会授权写操作或外部动作时，业务脚本先登记待确认动作，由宿主展示原始摘要并在用户选择确认后签发凭据。脚本写入前重新校验现场状态并一次性消费凭据。审批工具缺失、报错、取消或拒绝时停止并报告。实例、项目、分支和候选消歧仍用结构化提问，选项答案用于确定动作参数。三项门禁技能和确认门禁已迁到团队仓库 `ai_home`，宿主接入说明在该仓库的 `tools/confirm-gate/README.md`。
